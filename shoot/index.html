How it works

One card at a time, front then back. Before a photo is kept it is checked for an empty frame, blur, glare, framing, tilt, and whether you already shot that card today. Then it is straightened, cropped to the card and named to the convention.

Settings

Google Drive

From Google Cloud Console → Credentials → OAuth client ID → Web application, with this site added as an authorised JavaScript origin. Only the drive.file scope is requested, which is non-sensitive — the app can only see the files it creates.

Shoot

The existing library runs to card_0491, so starting at 500 keeps every number unique across the whole collection.

Card identification (optional)

A Cloudflare Worker that reads the two photos and fills in player, set and card number. Leave blank to skip it and type the details yourself.
