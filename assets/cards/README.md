# Card photos

Photos for cards that have no eBay listing to hotlink — everything in
`build/collection.tsv` with a `photo` value like `assets/cards/<file>.jpg`.

Resize to roughly 1200px on the long edge before committing. The same file is used
for both the grid tile and the lightbox, so anything much smaller looks soft when
enlarged and anything much larger just makes the repo heavy.

Name them after the card, matching the photo convention used for listings:
`Player-Name_CardNumber_front.jpg` — e.g. `Jacob-Fatu_GAM-10_front.jpg`.
